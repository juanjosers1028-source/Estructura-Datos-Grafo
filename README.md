# Estructura-Datos-Grafo
Integrantes: Jeronimo Hoyos
Juan Jose Renteria

Nuestro programaba estaba basado en una red social(Parecido a facebook) la cual nos dice y explica como se conectan las amistades que conocemos segun las redes sociales, por ejemplo la cuando aparece la opcion de "Sugerencia de amistad" Explicamos como se hace eso y la forma en la que se añaden amigos mediante un grafo BFS(Breadth First Search) para que nos fuese mas facil la busquedad y la explicacion de cada uno de estos.

Al momento de ejecutar el codigo apareceran 7 opciones: Agregar usuario, Eliminar Usuario, Agregar Amistad, Eliminar Amistad, Listar Amigos, Sugerir camino mas corto, Mostrar Matriz, Salir.

Cada una de estas opciones diseñadas para que el programa sea mas facil y optimo de utilizar ya que muestra como se puede añadir o eliminar un usuario o una amistad, muestra el camino mas corto que tomaria segun la matriz entre en 1 y 0 todo esto para identificarlo y explicarlo bien(1 Son amigo, 0 no son amigos) Esas serian las funciones principales y objetivos mas claros que queremos lograr con nuestro programa.
